# MiraçAkademi

MiraçAkademi, kullanıcıların çevrim içi eğitim içeriklerine erişebilmesini amaçlayan, Udemy benzeri bir eğitim platformu projesidir.

Proje, web geliştirme sürecinde edindiğim bilgileri uygulamak; frontend ve backend teknolojilerini bir araya getirerek kapsamlı bir web uygulaması geliştirmek amacıyla oluşturulmuştur.

## 🚀 Kullanılan Teknolojiler

- **Node.js** – Backend geliştirme
- **HTML5** – Sayfa yapısı
- **CSS3** – Tasarım ve stillendirme
- **JavaScript** – Dinamik kullanıcı etkileşimleri
- **SQL** – Veritabanı işlemleri

## 🎯 Projenin Amacı

MiraçAkademi'nin temel amacı, çevrim içi eğitim platformlarının çalışma mantığını anlamak ve eğitim odaklı bir web uygulaması geliştirmektir.

Bu proje ile web arayüzü geliştirme, sunucu taraflı programlama ve veritabanı yönetimi konularında pratik deneyim kazanılması hedeflenmiştir.

## 🛠️ Geliştirme Süreci

Proje geliştirilirken aşağıdaki konular üzerinde çalışılmıştır:

- Web arayüzü geliştirme
- Frontend ve backend teknolojilerinin birlikte kullanılması
- Node.js ile sunucu taraflı geliştirme
- SQL ile veritabanı işlemleri
- JavaScript ile dinamik işlemler
- Web uygulaması geliştirme süreçleri

## 📌 Proje Durumu

Proje, web geliştirme alanındaki bilgi ve becerilerimi geliştirmek amacıyla hazırladığım kişisel çalışmalarım arasında yer almaktadır.

Geliştirme sürecinde yeni özellikler ve iyileştirmeler eklenebilir.
